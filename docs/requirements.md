# 요구사항 문서

## 프로젝트 개요
한국형 크리에이터 안심 선물·후원 플랫폼. 팬은 크리에이터의 위시리스트에서 선물/후원을 결제하고, 크리에이터는 실제 주소를 노출하지 않은 상태로 선물과 메시지를 받는다.

## 대상 사용자
- 팬: 선물/후원을 보내는 사용자
- 크리에이터: 위시리스트를 운영하고 후원을 받는 사용자
- 관리자: 결제, 신고, 정산, 배송 상태를 운영하는 사용자

## MVP 기능
- 크리에이터 목록 및 상세 페이지
- 위시리스트 조회
- 후원/선물 결제 Mock 플로우
- 크리에이터 대시보드
- 관리자 대시보드
- API 서버 및 데이터 모델 골격

## 비기능 요구사항
- 개인정보 최소 노출
- 주소 마스킹
- 결제/알림 외부 API 키 분리
- GitHub Actions 기반 CI
- Docker 기반 DB/API 실행 준비

## 제외 범위
- 실제 PG 승인 호출
- 실제 카카오 알림톡 발송
- 실제 물류/배송 대행 연동
